# ABI 与数值配置

主线工具链使用 NPU ABI 1.0，以及随附当前案例采用的 `affine-int8-v1` 数值配置。张量布局、通道补齐、指令记录、量化规则和地址规划会写入每次编译生成的清单及文件。

主线 Depthwise V1 操作码为 `0x001C`。Depthwise Conv V2 候选使用 `0x001E`，位于 `examples/depthwise_conv_v2/candidate`；它的译码器、指令路径和 RTL 尚未并入主线 V1。随附旧板卡包保留各自原有的模型和 ABI 身份，应单独作为历史参考。

应同时查看编译清单、生成 RTL 清单和 IP 包清单，确认产物对应的模型、源码树和 ABI。不要混用来自不同清单的模型镜像、指令流、参数镜像或板卡包。
