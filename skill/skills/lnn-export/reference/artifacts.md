```verilog

`define CFC_N_LUT 1025
```

### 3.4 `known_limitations`（原文 4 条）与 7 条包内缺失条目

1. `demo scope: single fixed frequency (omega=1.0 rad/s), fixed delta_t=0.16, 8 fixed phases`
2. `int-vs-float difference includes weight/bias/input/activation quantization; float model uses delta_t=0.16, int model 655/4096`
3. `fixed-point delta_t is a positive Q12 value; RTL legal range 1..32767`
4. `sample json/npz are the ground truth for board-side plotting; only sample_000 is mirrored into x_input/y_expected/h_expected hex`

`files`/`files_meta` 的 40 条中 **7 条包内不存在**：2 条开发树 pyc（`export/__pycache__/cfc_spec.cpython-39.pyc`、
`export/__pycache__/int_reference.cpython-39.pyc`）+ 5 条开发树 `model/` 文件（见上）。驱动把"缺失"记 `missing`（只告警），
把"存在且哈希不符"记 `mismatch`（判失败）——pycache 陷阱的机制根源（troubleshooting T1）。包内可校验条目实为 **33** 条，
与 `board/lnn/README_BOARD.md` "export/ 内的 33 个文件随包分发且哈希可校验"一致。
本机实跑 `lnn_cfc_run.py --backend simulation-model` 的输出为 `manifest files: total=33 verified=33 mismatch=0 missing=7`
（missing 即上述 7 条，驱动只告警、不判失败），可直接作为该口径的复算证据。
